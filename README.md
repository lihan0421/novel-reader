# novel-reader 📖🕵️

摸鱼看小说，终端版。零第三方依赖——只要电脑上有 Node.js，随便哪台机器接上就能看，
不用装任何东西。支持本地 txt、在线搜索/热门推荐，还带三档"伪装等级"，从"正常好用"
一路到"看起来像 Claude Code 在写代码"，全看你工位风险等级。

## 这是什么 / 为什么会有这个

起因很简单：想在终端里看小说，但终端这东西天生显眼——一屏幕的中文小说正文，
路过的人扫一眼就知道你在干嘛。所以这个项目的核心命题其实不是"怎么读 txt"，
而是"怎么把读小说伪装成看起来像在干活"。三种显示模式、老板键、秒藏，都是为这个
目标服务的。

## 30 秒上手

```bash
node index.js
```

```
$ node index.js
[1] 继续阅读
[2] 本地书架
[3] 在线搜索
[4] 热门推荐
[5] 退出
>
```

- 第一次用：进 `[3] 在线搜索` 或 `[4] 热门推荐` 随便找本书开始看；也可以把自己的 txt
  丢进 `books/` 目录，从 `[2] 本地书架` 打开。
- 之后每次：直接 `[1] 继续阅读`，读过的书（不管本地还是在线）都在这，不用重新搜索，
  已经抓过的章节也不会重新联网爬。要是某本本地书对应的 txt 文件已经被删了/挪走了，
  这里会问你要不要把这条记录清掉，不会一直留着报错。
- **就算是在选书这几屏（主菜单/搜索结果/书单），按 `esc` 也能立刻秒藏**——不是只有
  进了阅读器才有这个能力，扫书单的时候老板路过一样能瞬间清屏。

## 三种"伪装等级"

阅读界面里按 `a` 循环切换，切换时会按比例把当前阅读位置换算过去，不会跳丢进度。

### 1. plain —— 老实人模式

啥也不装，就是一个好用的翻页阅读器，书名/章节/页码/按键提示全部亮出来。适合你已经
反复确认过身后没人的时候。

```
一个普通人，一个未知的系统，以思念作为动力的神灭具降临在斗罗大陆这个武魂的世界
又会发生什么样的故事呢……

面对伊库斯的视线，莉亚丝稍稍别过头去，不敢与他对视。她拿出一个红色的木匣子，
对着伊库斯说道。
------------------------------------------------------------
从斗罗大陆开始的赤龙帝 | 第1章 | 第 1/12 页 | 模式:plain
空格:下一页 p:上一页 N:下一章 P:上一章 a:切换模式 t:切换模板 h:秒藏 b:老板键 ?:帮助 q:退出
```

### 2. agent —— Claude Code 模式

翻页时排版模仿真实的 Claude Code 输出：先冒一条工具调用、一条灰色结果行，再来一段
"思考中"转圈动画，然后正文像大模型流式回复一样一个字一个字地打出来，最后跟一个
假的输入提示符收尾。**屏幕上不会出现任何"下一页/上一页"之类的按键说明**——真实的
工具调用输出不会自报按键，所以这些提示全都不显示，想看按键说明就按 `?` 临时瞄一眼。

```
⏺ Read(src/engine/handler.ts)
  ⎿  Read 42 lines

✻ Thinking… (2s · esc to interrupt)

从斗罗大陆开始的赤龙帝
作者：燚诚

一个普通人，一个未知的系统，以思念作为动力的神灭具降临在斗罗大陆这个武魂的
世界又会发生什么样的故事呢……

  ⎿  Done (1.2s)
>
```

（动画过程中按任意键会直接跳到正文，不用干等。）

### 3. inline —— 日志流模式（致敬 [tread](https://github.com/dkcn2006/tread)）

不清屏、不整页，翻页键每按一次只在终端底部追加一行，伪装成各种日志/工具输出滚动
过去。按 `t` 在 8 种模板之间切换：

```
[14:32:01] INFO  一个普通人，一个未知的系统，以思念作为动力的神灭具降临在斗罗
npm info run 大陆这个武魂的世界又会发生什么样的故事呢……
test_003.py::test_case PASSED  伊库斯看着手中的红色木匣子，若有所思
[14:32:03] [app] INFO  这是他送给你的生日礼物……你看看喜不喜欢……
2026-07-09T14:32:04.112Z INFO [pod-7f9c4] 莉亚丝稍稍别过头去，不敢与他对视
commit 5eb5727  她拿出一个红色的木匣子，对着伊库斯说道
// 伊库斯……阿诚……你爸爸还有奥菲斯妈妈  [第1章 | 42%]
一个普通人，一个未知的系统  (43%)
```

这个模式下屏幕上常驻的"新内容"永远只有一行，扫一眼几乎看不出在干嘛。代价是没有
"整页"概念：`p` 只是把光标退回一行（不会真的抹掉已经滚过去的旧内容），想往回翻很多
内容还是得靠终端自己的滚动条。

## 按键一览

| 按键 | 作用 |
| --- | --- |
| 空格 / n | 下一页（inline 模式下是下一行） |
| p | 上一页（inline 模式下是把光标退一行，不清屏） |
| N | 下一章（在线书） |
| P | 上一章（在线书，回退到本次会话来过的上一章） |
| a | 循环切换 plain / agent / inline 三种显示模式 |
| t | 循环切换 inline 模式的 8 种伪装模板（按了立刻能看到预览） |
| h / esc | 秒藏：立刻清屏留空，像个正常发呆的终端，再按一下恢复 |
| b | 老板键：切换成持续滚动的假日志界面，再按一次恢复 |
| ? | 临时打印一次完整状态和按键说明（不会常驻屏幕） |
| q | 退出并保存进度 |

`h`/`esc`/`b` 这三个"应急键"优先级最高——哪怕正好在联网抓下一章、或者 agent 模式的
"思考中"动画正播到一半，按下去也是立刻生效，不用等动画播完再按一次。

阅读进度不是只有按 `q` 退出才存：翻页、翻章、切模式的时候都会顺手存一下，就算中途
被强制关窗口也最多只丢最后一下操作，不会丢整个阅读进度。下次打开同一本书（不管是
从"本地书架""在线搜索"还是"继续阅读"进去）都会自动续读到上次的位置。

## 本地书架

把 txt 文件丢进 `books/` 目录即可，自动识别 UTF-8 / GBK 编码，中文 txt 常见的两种
编码都不用自己转。

## 在线书源

默认书源是「可乐小说网」(klxsw.cc) 的公开页面，仅供个人学习/摸鱼使用，不做二次分发。
抓取到的章节会永久缓存到 `data/cache/`，读过的内容离线也能看、也不会重复抓。这类免费
镜像站常年在改版、换域名，如果搜索或抓取突然失效，去看一下 `lib/source.js` 里的正则
是不是需要跟着新的页面结构调一下。

这个站的章节目录页是 JS 动态渲染出来的，简单请求拿不到完整目录，所以没有走"先抓
全书目录"的路子：打开一本书时只从详情页拿到真正的第一章链接（`og:novel:read_url`
这个 meta 标签），之后靠每章页面自带的"下一页/下一章"链接一路往下走
（见 `lib/onlineBook.js`）。网站上有些"章"会拆成好几个站内子页面（标题里带
"（第N页）"），会自动识别并拼成一整章。因为没有全目录，"上一章"只能回退到本次
打开书之后真的翻过的章节——不过这些也没什么影响，因为"继续阅读"菜单一直记得你
上次看到哪，用不着每次都从头翻。

网络请求都带了 15 秒超时，抓取失败会给一句人话（比如"翻章失败：请求超时，站点可能
没反应"）而不是让程序卡死或者崩掉——但不会帮你自动重试，失败了再按一次翻页/翻章键
就是了。爬到的文字也会过一遍清理：解码 `&hellip;`/`&mdash;` 这类 HTML 实体、滤掉
控制字符（防止镜像站的内容里混进终端转义序列），"下一页/下一章"链接也锁定只跟这个
站点自己打交道，不会因为页面里的一个链接就跑去请求别的域名。

### 把在线书整本下载到本地

在线书没有全书目录（原因见上面），平时都是一章一章顺着链接往下走、抓过的章节存进
`data/cache/` 就不再重新爬——这个够日常阅读用，但如果你就是想要一份完整的本地 txt
（比如想备份、想用别的工具看），在 `[1] 继续阅读` 里选中一本在线书的时候，序号前面
加个 `d` 就行，比如 `d2`：

```
1. [在线] 从斗罗大陆开始的赤龙帝
选书；在线书想整本下载到本地就输入 d+序号，比如 d2 (回车返回): d1
开始下载《从斗罗大陆开始的赤龙帝》，章节多的话要好几分钟，边下边存盘，中途 Ctrl+C 也不会白抓。
已下载 42 章：第四十二章 ...
```

会从第一章开始把整本书重新走一遍（已经缓存过的章节不用再联网，没缓存过的才会真的去
抓），每抓一章就往 `books/<书名>.txt` 里追加一次，不是等全部下完才写盘——网络断了
或者你自己 Ctrl+C 了，前面已经下好的部分也不会丢。下载完会自动把你原来在线读到的
位置换算成这份新 txt 里的行数，存成一条新的本地阅读记录，"继续阅读"里直接就能接着
看；原来那条在线记录还留着不会动，以后书上新章节了还能接着用在线的方式追更。

这个换算是按行数估算的，不是精确到字，正常情况下够用（跟本地书原本的翻页记录一样，
存的都是行号，终端宽度变了重开也会有点小误差，这是本来就有的取舍，不是这个功能特有
的问题）。

## 项目结构

```
novel-reader/
├── index.js              # 入口，主菜单（继续阅读/本地书架/在线搜索/热门推荐）
├── lib/
│   ├── library.js         # 本地 txt：扫描 books/、编码识别
│   ├── source.js          # 在线书源适配器：搜索/热门/章节抓取（klxsw.cc）
│   ├── onlineBook.js       # 把"一章可能分好几个站内子页面"这件事封装成统一接口
│   ├── downloadBook.js     # 把在线书整本走一遍、边下边存盘，换算成本地阅读进度
│   ├── bookCache.js        # 抓过的章节落盘缓存，读过的不会重复抓
│   ├── reader.js           # 阅读器主循环：翻页、三种显示模式、老板键、秒藏
│   ├── panicInput.js       # 主菜单/搜索/选书用的输入行，带 esc 秒藏
│   ├── atomicWrite.js       # 存档/缓存写文件都走临时文件+rename，防止写一半崩了炸库
│   ├── fakeAgent.js         # agent 模式用的假工具调用/结果行/思考动画素材
│   ├── inlineTemplates.js  # inline 模式的 8 种日志伪装模板
│   ├── bossKey.js           # 老板键用的滚动假日志
│   ├── textUtils.js        # 编码识别、HTML 解码、实体/控制字符过滤、按显示宽度分行
│   ├── progress.js         # 阅读进度存取 + "继续阅读"列表
│   └── paths.js            # 各种目录路径
├── books/                 # 你自己丢 txt 进来的地方
└── test/                  # node:test 单测
```

## 测试

```bash
npm test
```

覆盖分页换行逻辑、编码识别、进度存取这几块纯逻辑代码。翻页/伪装动画这些交互部分
靠手动跑一遍验证——毕竟总不能自动化按空格来验证"这个动画好不好看"。
