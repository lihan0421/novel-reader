# novel-reader

终端摸鱼小说阅读器。零第三方依赖，只要装了 Node.js (>=18) 就能跑。

## 使用

```
node index.js
```

主菜单：

```
[1] 本地书架    读 books/ 目录下的 txt 文件
[2] 在线搜索    按关键字搜索默认在线书源
[3] 热门推荐    浏览默认书源首页推荐
[4] 退出
```

阅读器按键：

| 按键 | 作用 |
| --- | --- |
| 空格 / n | 下一页 |
| p | 上一页 |
| N | 下一章（在线书） |
| P | 上一章（在线书，回退到本次会话来过的上一章） |
| a | 切换伪装模式：翻页时正文变成逐字流式输出，中间穿插假的 `⏺ Read(...)` 工具调用行和 `✻ Thinking…` 转圈动画，看起来像 Claude Code 在干活。动画途中按任意键可以直接跳过 |
| b | 老板键：切换成假日志滚动界面，再按一次恢复 |
| q | 退出并保存进度 |

阅读进度按书自动保存在 `data/progress.json`，下次打开同一本书会自动续读。

## 本地书架

把 txt 文件丢进 `books/` 目录即可，自动识别 UTF-8 / GBK 编码。

## 在线书源

默认书源是「可乐小说网」(klxsw.cc) 的公开页面，仅供个人学习/摸鱼使用。抓取到的章节会缓存到
`data/cache/`，读过的章节离线也能看。这类免费站点常年在改版、换域名，如果搜索或抓取突然失效，
去看一下 `lib/source.js` 里的正则是不是需要跟着新的页面结构调一下。

这个站的章节目录页是 JS 动态渲染的，简单请求拿不到完整目录，所以没有走"先抓全书目录"的路子：
打开一本书时只从详情页拿到真正的第一章链接（`og:novel:read_url`），之后靠每章页面自带的
"下一页/下一章"链接一路往下走（`lib/onlineBook.js`）。网站上有些"章"会拆成好几个站内子页面
（标题带"（第N页）"），会自动拼成一整章。因为没有全目录，"上一章"只能回退到本次打开书之后
真的翻过的章节，还没深入翻过的更早章节暂时翻不回去。
