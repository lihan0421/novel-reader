# novel-reader

终端摸鱼小说阅读器。零第三方依赖，只要装了 Node.js (>=18) 就能跑。

## 使用

```
node index.js
```

主菜单：

```
[1] 本地书架    读 books/ 目录下的 txt 文件
[2] 在线搜索    按关键字搜索默认在线书源
[3] 热门推荐    浏览默认书源首页推荐
[4] 退出
```

## 显示模式

按 `a` 循环切换三种模式：

- **plain（默认）**：整页显示，屏幕上有完整的书名/页码/按键提示 —— 不装，就是单纯好用，适合你确定没人看屏幕的时候。
- **agent**：整页显示，但排版模仿 Claude Code：先冒一条 `⏺ Read(...)` 工具调用行和一条灰色的 `⎿` 结果行，再来一段 `✻ Thinking…` 转圈动画，然后正文逐字流式打出来，最后跟一个假的 `>` 输入提示符收尾。屏幕上不会出现任何"下一页/上一页"之类的按键说明——真实的工具调用输出也不会自报按键，所以这些提示都不显示，全靠你记住按键（或按 `?` 临时看一眼）。
- **inline**：参考 [tread](https://github.com/dkcn2006/tread) 的思路，不清屏、不整页，每按一次翻页键只在终端底部追加一行，伪装成 npm/pytest/docker/kubectl/git log/代码注释等 8 种日志格式之一滚动过去，屏幕上常驻的文字量最少。按 `t` 循环切换这 8 种模板。这个模式下没有"整页"概念，`p` 只是把光标退回一行（不会真的抹掉已经滚过去的内容），`N`/`P` 换章逻辑不变。

三种模式共用同一份阅读进度和翻页逻辑，切换模式时会按比例把当前位置换算过去，不会跳丢。

阅读器按键：

| 按键 | 作用 |
| --- | --- |
| 空格 / n | 下一页（inline 模式下是下一行） |
| p | 上一页（inline 模式下是把光标退一行，不清屏） |
| N | 下一章（在线书） |
| P | 上一章（在线书，回退到本次会话来过的上一章） |
| a | 循环切换 plain / agent / inline 三种显示模式 |
| t | 循环切换 inline 模式的 8 种伪装模板 |
| h | 秒藏：立刻清屏，屏幕留空像正常终端一样，按任意键恢复 |
| b | 老板键：切换成持续滚动的假日志界面，再按一次恢复 |
| ? | 临时打印一次完整状态和按键说明（不会常驻） |
| q | 退出并保存进度 |

阅读进度按书自动保存在 `data/progress.json`，下次打开同一本书会自动续读。

## 本地书架

把 txt 文件丢进 `books/` 目录即可，自动识别 UTF-8 / GBK 编码。

## 在线书源

默认书源是「可乐小说网」(klxsw.cc) 的公开页面，仅供个人学习/摸鱼使用。抓取到的章节会缓存到
`data/cache/`，读过的章节离线也能看。这类免费站点常年在改版、换域名，如果搜索或抓取突然失效，
去看一下 `lib/source.js` 里的正则是不是需要跟着新的页面结构调一下。

这个站的章节目录页是 JS 动态渲染的，简单请求拿不到完整目录，所以没有走"先抓全书目录"的路子：
打开一本书时只从详情页拿到真正的第一章链接（`og:novel:read_url`），之后靠每章页面自带的
"下一页/下一章"链接一路往下走（`lib/onlineBook.js`）。网站上有些"章"会拆成好几个站内子页面
（标题带"（第N页）"），会自动拼成一整章。因为没有全目录，"上一章"只能回退到本次打开书之后
真的翻过的章节，还没深入翻过的更早章节暂时翻不回去。
